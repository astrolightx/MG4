## Devlog
Explain how the FloatAnimation script works to animate the fish food GameObjects up and down. Make sure to mention the Start() and Update() methods and _up and _timer variables. You can ignore the StopAnimation() method.
The FloatAnimation script animates the fish food game objects up and down by using methods. Such methods would be the Start() and Update() methods. The start method is in its name, it starts the animation while the update method continues the movement by each frame. The _up and _timer are variables within the method that makes the food go up & down when the timer hits zero, respectively.
